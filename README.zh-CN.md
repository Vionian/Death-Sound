# Death Sound 中文说明

`Death Sound` 是《战锤40K：暗潮》的本地音效替换 mod，用自定义文件替换队友倒地和阵亡时的提示音。项目已经内置 `SimpleAudio` 运行库，不需要额外安装独立的音频库 mod。

## 使用方式

1. 把 `Death Sound` 文件夹复制到游戏的 `mods` 目录。
2. 把倒地音效放到 `Death Sound/audio/downed/`，阵亡音效放到 `Death Sound/audio/dead/`。
3. 添加或替换文件后重启游戏，让设置页重新扫描文件。

支持 `mp3`、`wav`、`ogg`、`flac`、`m4a`、`aac`、`wma`、`opus`、`mp4` 和 `webm`。文件名支持中文。

## 设置

倒地和阵亡各自拥有一套独立选项：

- 是否替换自己或队友的声音；
- 音量；
- 固定替换，播放选中的文件；
- 随机替换，使用洗牌后的音效袋，同一轮内会尽量用完所有文件后再重复。

选择固定音效后会自动播放短试听。队友开关只针对真人队友，机器人保留游戏原本的声音。

## 大致原理

mod 在进入任务时扫描 `audio/downed/` 和 `audio/dead/`，按事件分别保存可用音频。它 hook 游戏 HUD 的个人和队伍玩家面板，从面板状态判断玩家是正常、倒地还是阵亡；状态变化时调用内置音频运行库播放对应文件。

播放期间会根据玩家单位更新空间位置，所以声音可以跟随角色所在位置。随机模式使用 Fisher-Yates 洗牌生成一轮播放袋，固定模式则校验设置页选中的文件是否仍然存在。
